# СЭВТ — прототипы сайта savt.ru

Этап 1 «Разработка прототипов» по заданию Заказчика от 17.07.2026.

- `prototype/index.html` — кликабельный прототип. Откройте файл в браузере: переключение страниц и устройств (десктоп / планшет / мобильный) на верхней панели, галочка «Пояснения» показывает комментарии к блокам.
- `prototype/savt-prototype.pdf` — те же страницы в PDF (десктоп 1440 px и мобильная версия 375 px, окно «Запросить КП»).

Страницы: Главная, Продукты, Категория «Серверы», Товар (СЭВТ LGA4189 / LGA3647), Решения и услуги, Контакты, Карта сайта.
